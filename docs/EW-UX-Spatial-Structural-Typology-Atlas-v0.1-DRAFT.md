# EW-UX Spatial & Structural Typology Atlas v0.1

> **Working Draft / Research Intake — NOT FROZEN, NOT ACCEPTED.** 2026-11-10。
> 这是本项目用户原始清单与 Chat 讨论所形成的 **6 类、48 种候选类型、12 组核心验证场景**的完整归档。用于后续系统化去重、补漏、类型不变量和覆盖差距评审；不构成已通过的建筑设计合同或已实现测试清单。
>
> 仓库：[ew-ux-atlas](https://github.com/happygq/ew-ux-atlas) · [新窗口交接说明](./TYPOLOGY-ATLAS-HANDOFF.md) · [项目状态](./PROJECT-STATUS.md)。

## 1. 目的与 Townscaper 参考边界

以 Townscaper 程序化建造为**视觉自动生成和局部构件拼装**的参考：极简单元放置产生街巷、屋面、拱廊、楼梯、桥、围院或高架体量等丰富外观。但不可推论 Townscaper 已经具备或验证了以下 48 种布局的完整空间通行、物理承托或建筑工程安全。

EW-UX 的研究目标是：让 **Add / Recolor / Remove** 仍然是主要用户动作，而由清晰的空间、围护、通行、支撑及屋盖规则**自动生成或提出可解释候选**。用户建造期的状态必须确定性重放，不能用好看的模型掩盖不合法空域或支撑。此 Atlas 同时区分：
- **形态生成**：外观构件自动适配（Townscaper 强项）。
- **空间语义**：占用、RoomRegion / CourtyardRegion / VoidRegion3D、层间关系。
- **结构与通行语义**：SupportGraph、PassageGraph、楼板孔洞和支持路径。
- **真实几何**：构件实体、柱梁、门窗孔、楼梯、屋盖、排水。
- **工程安全**：受力与材料规范验证，**当前研究范围未证明**。
- **幻想机制**：EW 可设置特殊物理规则；必须显式标注，不能混入常规结构规则。

## 2. 六大类、48 种候选类型

### H · 水平房间组合（7）

| 类型 | 候选布局 / 构造 | 核心空间或结构不变量 |
|---|---|---|
| H01 | 单单元独立房间 | 完整围护、独立屋盖及入口归属，外墙无重复 |
| H02 | 同层多单元连续大房间 | 以持久 OPEN 求连通，连续柱网与大跨几何分离 |
| H03 | L/T/U 形连续大房间 | 转角及交汇节点墙/柱/屋盖归属唯一 |
| H04 | 异形、斜角及非矩形房间 | 邻接由实际几何边界定义，不能仅依赖方格 |
| H05 | 贴邻但不相通的房间 | 共享隔墙唯一；贴邻、相通与可通行互不等价 |
| H06 | 内门/走廊连接的多房间 | RoomRegion 与 PassageGraph 各自独立 |
| H07 | 独立房屋贴邻及连体组团 | 建筑身份与共墙、入口、界面/扩建历史明确 |

### V · 垂直房间及跨层空间（7）

| 类型 | 候选布局 / 构造 | 核心空间或结构不变量 |
|---|---|---|
| V01 | 二层/三层正上方叠置房间 | 垂直接触不自动形成楼梯，楼板与支持关系独立 |
| V02 | 不同层平面及逐层错退房间 | 上层支撑路径稳定，高低屋盖不重复 |
| V03 | 错层、半层和夹层 | 标高/楼板连续性不能由整数 level 推断 |
| V04 | 两层通高的封闭室内大房间 | 中间没有楼板，VoidRegion3D 与围护/封顶独立 |
| V05 | 三层贯通的室内挑空 | 多层空域连续，局部平台不能误封闭 |
| V06 | 局部一层、局部二层混合体量 | 外露屋面及接墙/上层边界合法 |
| V07 | 下层多小间、上层大间（及反向） | 层间房间分割不同，通行和承托不随分割自动推定 |

### C · 庭院、天井及开放空域（9）

| 类型 | 候选布局 / 构造 | 核心空间或结构不变量 |
|---|---|---|
| C01 | 四面围合的单层露天庭院 | 由围合事实推导院落而不是预置对象 |
| C02 | 狭窄采光天井 | 小尺度仍需真实竖向空域、边界和排水 |
| C03 | L 形、异形、多边形围合院落 | 不能用矩形环检测替代一般围合计算 |
| C04 | 单面围墙的开放院落 | 墙界定区≠封闭庭院，围合程度明确 |
| C05 | U 形/三面围合半开放庭院 | 真实开口连至室外或巷道，分类为半开放 |
| C06 | 双院、多进院、院—巷—院 | 多个 CourtyardRegion 身份分离、通道真实 |
| C07 | 贯通二/三层的露天天井 | 连续向天空的 VoidRegion3D；上层围廊可共存 |
| C08 | 局部有顶、天窗或盖檐的中庭式院落 | 遮盖状态、实际露天程度与采光分离 |
| C09 | 中央完全有屋顶的室内中庭 | 同是挑空但属于封顶室内，不误认露天院 |

### P · 楼梯、连廊和交通网络（8）

| 类型 | 候选布局 / 构造 | 核心空间或结构不变量 |
|---|---|---|
| P01 | 室外—房间—庭院入口链 | 真正门洞/通行边存在才确认连通 |
| P02 | 沿外墙设置的外部楼梯 | 楼梯起落平台与上层入口匹配 |
| P03 | 室内楼梯 | 真实 SlabOpening、竖向 PassageGraph 和净空 |
| P04 | 折返、转角、螺旋楼梯 | 路径、楼板洞和空间占用一致 |
| P05 | 底层穿堂、拱门和下穿通道 | 上层实体与底部空域同处一个体量而不冲突 |
| P06 | 二/三层连桥、过街高架 | 双端有效连接；桥下仍是自由空域 |
| P07 | 阳台、外廊、内院回廊 | 楼面、栏杆、通行边和支撑区分 |
| P08 | 多层巷道、转角/袋形巷 | 死路与出口分类正确，误判可达性被禁止 |

### S · 复杂立柱及承托结构（11）

| 类型 | 候选布局 / 构造 | 核心空间或结构不变量 |
|---|---|---|
| S01 | 单层落地房间 | 直接以地面或允许承载面作为支持源 |
| S02 | 上层由下层完整房间承托 | 承托来源和路径明确但不等于力学合规 |
| S03 | 四根落地柱完全架空房间 | 四柱脚及梁板的支撑关系，底层保持空域 |
| S04 | 二层两根落地柱＋底层房间支撑 | 柱脚在地面，另一部分由底层房间共同支持 |
| S05 | 三层两根贯通落地柱＋下部房间支撑 | 柱跨层延续并落地，不能错记为一层屋面柱脚 |
| S06 | 三层两柱立于一层房屋＋二层房间支撑 | 柱脚在下层房屋承载结构，形成多级支持链 |
| S07 | 三根不对称立柱支撑 | 非对称多源支持及方向性路径 |
| S08 | 单根主柱＋核心体量共同支撑 | 集中与多源并存，不预设真实抗倾覆合法 |
| S09 | 两侧实体跨院/跨巷承托房间 | 多跨/桥接支撑不封堵下方空间 |
| S10 | 单侧悬挑上层房间 | 悬挑约束和后锚支撑明确，结构受力另证 |
| S11 | 完全无可见柱的漂浮房间 | 只能经显式幻想机制许可，不能默认物理承托合法 |

### R · 屋面、平台和建筑组团（6）

| 类型 | 候选布局 / 构造 | 核心空间或结构不变量 |
|---|---|---|
| R01 | 单坡/双坡及多坡向屋面 | 屋盖覆面与包络一致、坡向正确 |
| R02 | L/T/U 交汇、屋脊及谷线 | 屋面交界唯一，谷线排水不能穿过室内 |
| R03 | 错层屋盖、连续高低马头墙 | 高低山墙和屋面不互穿 |
| R04 | 平屋顶露台、护栏和屋顶加建 | 可进入屋面与防水/支撑状态分离 |
| R05 | 屋顶花园、屋顶院落及局部采光井 | 屋面使用、开天孔、排水和围护并存 |
| R06 | 连片/断开屋盖及交错建筑组团 | 共墙、檐口、巷道、细碎间隙、排水有确定归属 |

**索引统计：H 7 + V 7 + C 9 + P 8 + S 11 + R 6 = 48。**

## 3. 类型交叉、去重与尚待补漏

该清单按*主要研究对象*分组，并非六个互斥集合。具体关联待新窗口评审：
- H04 与 C03 都使用非矩形边界能力：**共享几何条件**但一个是房间、一个是院落。
- V04/V05 与 C07/C09 同为垂直空域：必须根据**围护、屋顶、天空可达**区分室内通高与露天竖井。
- C08 与 R05 分别从院落空域和上方屋盖的角度观察同一组合；可有多对多引用。
- P06 和 S09 同一跨接体量可能同时存在，但其**通行关系**与**承托关系**是独立图。
- H07、R06 分别处理建筑组团身份与屋盖界面；不宜轻率合并。
- S04/S05/S06 的两柱构件表面相似，但柱脚到底落地、跨层连续或落在下层房屋上，承托来源与依赖链不同，**不能去重合并**。
- **尚待补漏检查**：不规则网格与局部边界、不同层高/错层、地形/水面基础、建筑层间封闭空域、单墙弱围合、四柱以下/非对称承托、楼梯落脚与障碍净空、悬挑合法性、庭院排水、动态重组的边界条件。

## 4. 跨类型的不变量

1. **Occupancy3D / 身份**：显式 `x,z,level` 或标高；建造历史、房间身份和建筑身份分离。删除再建分配新身份，未受影响的单元身份稳定。
2. **HorizontalEdgeFacts / 水平联系**：单层 R1 的持久 `OPEN/PARTITION` 不因 Recolor 追溯改变。相邻、贴墙、室内相连、门洞可通行不是一个概念。
3. **VoidRegion3D / 空域**：同一上空可能局部遮盖但仍由邻近空域通天；区分露天空域、内部挑空、遮盖中庭、桥下通道。天空连通不等于可供人员行走。
4. **SupportGraph / 承托**：支持来源（地、墙、柱、梁、房间、幻想锚）及路径可追踪，多源和多层柱脚不能压成单一“下方有单元”判断；Remove 后必须安全拒绝或经批准重组。
5. **PassageGraph / 交通**：从几何接触推导楼梯**候选**不等于存在楼梯。真实竖向可通行必须有起落平台、楼板开孔、路径和净空证据。
6. **Envelope/Geometry / 构件归属**：唯一共墙、门窗真实洞口、合法柱/梁/楼板/屋盖交汇；院/巷剩余狭缝不能假装成可用交通空间。
7. **Change / Replay**：每组场景必须有从空场景开始的 Add/Recolor/Remove 操作前缀、成功及失败反例、状态/标识稳定性、确定性对照。
8. **Evidence / 范围**：语义通过≠真实几何通过≠工程安全通过≠用户手机视觉验收通过。

### 支持链细分：S04 / S05 / S06

- **S04**：二层体量一部分支在一层房间上、另一部分由**直接落地的双柱**支撑。
- **S05**：三层体量的双柱**贯穿较低楼层落地**，兼有下部房间的承载关系；需检验跨层立柱是否贯穿下部空间。
- **S06**：三层体量的双柱**落在一层房屋的合法承载构件上**，并与二层房间共同支撑；绝不可当作 S05 的落地柱。

研究阶段先证明支持源和依赖链可解释；梁柱尺寸、受力与节点属于后续几何/工程问题。

## 5. 十二组最小覆盖场景（建议初版）

| 场景 | 涉及类型 | 组合建造操作路径 | 核心验证目标 | 优先阶段 |
|---|---|---|---|---|
| T01 | H01/H02/H05/H06 | 单房间→水平大房间→相邻独立间→室内门候选 | 同层持久 OPEN/PARTITION，不提前宣称真实洞口 | R2-V / R2-B |
| T02 | V01/V02/S02 | 二层直叠→三层错退 | 楼层身份、接触与支撑依赖 | R2-V |
| T03 | V04/V05/C09 | 两层挑空→三层挑空→顶部封屋盖 | 室内通高和露天状态必须分开 | R2-V→R3-V |
| T04 | C01/C02/C07 | 单层围院→二层/三层贯通天井 | 真实三维空域/天窗、回廊和环绕房间 | R2-V→R3-V |
| T05 | C03/C04/C05/C06 | 单面围墙→U 形半开放→异形多进/双院 | 庭院开放等级、独立 Region 和多出口 | R2-V |
| T06 | C08/C09/R05 | 露天院→局部加盖→完全封顶 | 天空连通与采光、屋顶几何分离 | R2-V→R3-V |
| T07 | P02/P03/P04 | 外墙梯→内楼梯→转角梯 | 楼梯候选、楼板孔洞、真实可达图分开验证 | R2-V→R3-V |
| T08 | P05/P06/P08/S09 | 底层穿堂→跨巷连桥 | 上层承托、下层空域和跨层通行同时合法 | R2-V→R3-V |
| T09 | S03/S07 | 四落地柱架空→三柱不对称 | 多源支持图及下部空域不被占用 | R2-V→R3-V |
| T10 | S04/S05/S06 | 三种双柱＋房间混合承托 | 落地柱 vs 贯通柱 vs 柱脚立于下层房屋 | R2-V→R3-V |
| T11 | S08/S09/S10/S11 | 核心＋柱→大跨→悬挑→幻想漂浮边界 | 常规路径与世界特许规则分层，负例必须有 | R2-V→R3-V |
| T12 | H07/V07/P07/R02/R03/R06 | 建筑组团在跨层 Add/Recolor/Remove 后重组 | 受影响闭包、稳定 ID、几何和通行/排水变化 | R2-V→R3-V |

**每组的正式验收证据模板**：最小操作序列 + 每步合法模型/图快照 + 关键不变量 + 反例/拒绝与可解释原因 + Remove→Add 重组 + 稳定身份/重放 + 实体/视觉证据（按阶段）。**当前仅是候选覆盖矩阵；12 组尚未执行完毕。**

## 6. 横向变化维度（不额外计入 48 类）

- 场地条件：平地、水面、坡地、台阶基座，以及悬空/幻想锚定。
- 网格条件：正交方格、非规则网格、斜边/非正交邻接、局部不同尺度。
- 标高条件：单层、二/三层、高低错层、夹层、不等层高。
- 建造历史：单元颜色和颜色历史、先合并再改色、删除支持源、重建、不同建筑所有权。
- 围护与屋盖：无屋盖、部分屋盖、天窗、平屋顶露台、连续斜屋盖与雨水汇流。
- 空域使用：封闭室内、庭院/天井、桥下、阳台、回廊、门洞、楼梯与巷道。
- 支撑与例外：直接落地、完整承载体、多柱/混合/悬挑及授权幻想机制。

## 7. 与当前研究成果的差距（初步，不是代码审查结论）

| 基线 | 已有证据 | 尚不能外推 |
|---|---|---|
| **R1（单层已验收）** | Add/Recolor/Remove；历史 OPEN/PARTITION；单层围合/双院和示意内立面 | 二/三层、真实门窗/屋顶、楼梯、复杂柱梁 |
| **R2-V Stage 1** | V01–V04 的 2/3 层基本占用、直接支持/简化一跨候选、非法 Remove/Add 拒绝 | 实体结构安全、跨层真实通行 |
| **R2-V Stage 2** | V05 承托候选切换；V06 楼梯**未实现**候选；V07 三维空域与部分遮盖；本地报告 26/26 定向测试 | 多柱多源支持、真实 SlabOpening 和竖向 PassageGraph、48 类全面覆盖 |
| **G1 屋面/街巷原型** | 单体模块、L/T/U、层叠街巷的视觉与局部规则研究 | 非规则格网、综合多层真实构件、混合屋盖连续性、残余狭缝 |
| **R3-V / R4（未实现）** | 已有阶段/验收关口计划 | 二/三层完整几何和手机三视角验收 |

[多层验证计划](./MULTISTORY-VALIDATION-PLAN-v0.1.md)仍有效，**G-V1 保持 OPEN，R2-A 不冻结**。类型研究是其前置覆盖分析，不自动重开既有 R1 验收，亦不触碰正式 WP1.1 Authority。

## 8. 新窗口的第一轮工作（现在还没有完成）

1. 对六大类的命名、互斥性与跨类型关系做严格去重；检查用户原始类型及 Townscaper 造型参考是否有遗漏。
2. 把每种类型改写成**可检查的不变量和依赖**；按占用/空域/支持/交通/围护/屋盖五个语义面建立类型关联图。
3. 用 **Existing / Partial / Missing / Deferred** 标记 R1、R2-V Stage2 的覆盖情况，并提供**可审计的证据来源**，不能自行把已存在视觉候选推断为通过。
4. 审核 12 组场景的最小性、反例与组合覆盖；明确哪些必须在 G-V1 前验证，哪些属于 R3-V/G-V2 或 R4。
5. 输出 Atlas v0.1 的评审结论、未决技术选项和项目计划调整建议；**此阶段不要求开始编码**。
