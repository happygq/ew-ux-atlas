# EW-UX · 二/三层验证计划 v0.1（R2-V + R3-V）

> **状态：已批准纳入计划 / 尚未实现和验收** · 2026-11-10。仅作用于 EW-UX 独立研究，不更改 WP1.1 Authority、R2.3 或已冻结的 [v0.1](./EW-UX-Architectural-Construction-Baseline-v0.1.md) / [v0.2](./EW-UX-Architectural-Construction-Baseline-v0.2.md) 建筑设计基线。

## 0. 范围确认

用户已确认 CS–CY–IW–DW / R1 的研究交互和视觉可接受。**R1 的证据严格限于单层**：室内连接、建造历史、平面庭院围合及剖开屋顶的示意立面；18/18 是此前记录的单层语义测试，不等于多层通过，也不证明真实门窗、完整屋顶、结构受力和天井实际可达。R1 已验收结果不因本计划重新打开。

目标：在真实 R2 墙体/开口几何合同冻结前，用最小的二、三层操作回放证伪可能的二维假设；然后在 R3 用真实三维几何完成联合验证。**不可简单把 2D RoomRegion / CourtyardRegion 沿 Y 复制，或依赖外观叠楼证明结构合法。**

## 1. 分阶段准入顺序

1. **R2-A（合同草案）**：定义 Floor/Level 身份、Occupancy3D、水平/垂直接触、楼板、支撑依赖、垂直通行、Void / CourtyardRegion3D 和 Opening 的最小边界；文档草案不表示合同已冻结。
2. **R2-V（G-V1，强制前置）**：实际运行 V01–V04 以及有效和无效输入回放，记录每步状态、确定性哈希、错误/拒绝与支持路径。没有 G-V1 通过，不得宣称 R2-A 对多层已冻结。
3. **R2-B/C**：按通过的合同构造连续墙/木柱/梁/石脚/白墙和真实开孔，验证 Add/Remove 的几何重组，保持 R1 持久边不变量；不得以假窗或贴面完成实体 Gate。
4. **R3 + R3-V（G-V2）**：二/三层的楼板、柱梁、楼梯与门槛、跨层天井空域、马头墙、屋顶/谷线、排水和院—室—巷交通构成完整合法网格及可验证路径。未经实证不能宣称受力安全或历史建筑复原。
5. **R4（多层视觉 Gate）**：单层、二层、三层分别以街巷外观、庭院内立面和去屋顶室内视角作真机验证；相机/指南针、材质颜色不能改变拓扑状态。

R2-V 与 R2-A **联合设计但先于 R2-A 多层适用性冻结**；R3-V 是实体几何 Gate，不能用 R2-V 的语义通过代替。

## 2. 多层语义的不变量

- **身份与连接：** 每个单元有稳定的二维位置和显式楼层/高程身份；平面贴邻、上下接触、室内可通行是三个不同事实。上下叠置**不自动生成楼梯或通行口**。
- **持久边：** R1 的 `OPEN/PARTITION` 历史不追溯，Recolor 不改变已存连接。新增垂直关系应单独记录、可重放、可区分可通行与可承托。
- **承托路径：** 允许的上层建筑应具有合法的承托链。Remove 下层承托时，必须确定性拒绝、或执行经独立设计批准的受控重组；不能静默留下悬空楼板，也不能擅自移位既存单元。**这里不冻结倒塌/连锁拆除策略**。
- **三维庭院：** CourtyardRegion 必须区分平面围合与竖向对天开敞、层间楼板孔洞、局部廊檐遮盖。屋内空洞不因平面封闭自动变成露天天井；真正通道必须以可通行边和真实开口构成。
- **重放和稳定：** 从同一 Add / Recolor / Remove 操作日志得到同样的房间、支撑、开口意图和错误结果。未受影响的墙段、空间、楼层身份不得无故重排。
- **隔离：** 这是 UX 研究语义；不修改 Authority 提交合同，也不把实验室承托规则宣称为符合建筑规范的结构计算。

## 3. G-V1：R2-V 四组固定场景

| 场景 | 从空状态建造的最小输入 | 通过条件 |
| --- | --- | --- |
| **V01 二层紧凑住宅** | 首层相邻单元 → 二层同位置单元 → 选定竖向通行意图 | 分层房间与水平边正确；上下接触不自动室内连通；承托链有确定性证据 |
| **V02 二层贯通天井** | 一层围合庭院 → 二层围廊/局部退让形成开天空域 | 庭院高度、楼板遮挡/孔洞和露天属性正确；不能把楼板盖住的空间误判为贯通天井 |
| **V03 三层阶梯住宅** | 第一、二、三层各使用不同合法平面，逐步错退 | 占用、承托、竖向边界、建筑/房间身份正确；非法无支撑 Add 明确拒绝 |
| **V04 二/三层 Add–Recolor–Remove** | 插入/删除中层与底层承托、重添、改色，包含负例 | 支撑依赖处理有确定性且可解释的结果；R1 已建边不追溯；完整重放字节一致 |

**G-V1 退出条件：** 四组场景含可重复操作序列、每步 Room/Floor/Courtyard/Support/Passage 快照、合法/非法负例、确定性对照、测试运行记录及独立技术审查。纯演示动画或单一截图不足以关闭 G-V1。

## 4. G-V2：R3-V 实体几何

- 至少一组**二层**和一组**三层**完整建造回放；可检查楼板与楼梯的实体孔洞、真实可通行门洞和界面、梁柱/墙体承托、马头墙-屋面、天井采光与排水路径。
- 对照同一输入跨状态与视角，检查重复墙、几何冲突、悬空构件、楼梯与门槛互穿、错误封闭天井、雨水误排室内和 Remove 后的悬挂构件；网格测试须声明覆盖范围。
- 需明确区分**几何/路径/排水可解释性**与**真实工程力学安全**，不能将研究测试误称为结构安全认证。
- 完成 G-V2 后才进行 R4 的二/三层真机美学和性能验收。
